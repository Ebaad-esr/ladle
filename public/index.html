LadleTrack-2FA

A Two-Factor Authentication Tracking System for Steel Ladles

Theme: Industry 4.0 / Smart Automation | Category: Software

The Problem & Our Solution

The Problem: Manual ladle tracking is dangerous and unreliable. Single-technology automated systems (like just RFID or just cameras) are vulnerable to single points of failure, such as a damaged tag or an unreadable number, which can lead to costly mix-ups.

Our Solution: A network of intelligent "Smart Stations" that uses a two-factor authentication (2FA) process to guarantee the correct identification and location of every ladle, every time.

How It Works (Two-Factor Authentication)

  • Factor 1: RFID Identification (Primary ID): Each ladle is fitted with a passive, battery-free, Industrial High-Temperature UHF RFID Tag. This provides a fast, reliable, all-weather primary identification.
  • Factor 2: Visual Verification (Secondary ID): Each "Smart Station" is also equipped with an ESP32-CAM. This low-cost camera captures an image of the ladle's painted number for AI-powered visual confirmation.

The Process: When a ladle passes a station, the system reads both the RFID tag and the painted number. The data is sent to a cloud backend where the two IDs are cross-referenced. A match provides 100% confirmation, while a mismatch triggers an immediate alert. No expensive on-site server is required.

Innovation: Our solution introduces a novel two-factor authentication approach to industrial asset tracking. By cross-validating a robust electronic ID (RFID) with a visual ID (camera OCR), we create a "digital cross-check" system that is far more reliable and error-proof than any single-method solution, all while maintaining an extremely low cost.

Technical Architecture & Workflow

Tech Stack:

  • Hardware: Industrial High-Temperature UHF RFID Tags, Industrial UHF RFID Readers, ESP32 Microcontrollers, ESP32-CAM Modules.
  • Cloud & Backend: Serverless Functions (e.g., AWS Lambda, Vercel Functions), Serverless Database (e.g., Neon).
  • AI & Vision: OpenCV, EasyOCR for character recognition on the cloud backend.
  • Frontend: React.js / Next.js for a live web-based dashboard.

System Workflow:

(A simple flowchart would be placed here illustrating the following 5 steps):

  1. Dual Capture: A ladle passes a "Smart Station." The station's ESP32 controller simultaneously reads the RFID Tag ID and captures an image of the painted number.
  2. Transmission: The ESP32 sends both the RFID ID and the image to a secure cloud endpoint via Wi-Fi.
  3. Cloud-Side Verification (2FA): A serverless function is triggered, which looks up the RFID ID in a database and runs OCR on the image.
  4. Confirmation: The system compares the two numbers. A match confirms the ladle's identity and updates its location. A mismatch flags an alert.
  5. Visualization: The live web dashboard queries the database to display the confirmed, real-time location of all ladles.

Impact & Viability

Feasibility & Viability:

  • Technically Feasible: Uses proven industrial RFID and low-cost ESP32-CAMs. AI-based OCR can be run efficiently on a serverless cloud backend.
  • Economically Viable: The two-factor system is achieved with minimal extra cost. The serverless architecture eliminates costly on-site hardware.
  • Operationally Viable: Designed for 24/7 autonomous operation with a built-in fallback if one identification method fails.

Impact & Benefits:

  • Enhanced Safety & Error Prevention: Virtually eliminates ladle mix-ups, preventing accidents and costly production errors.
  • Increased Reliability: More resilient than single-ID methods, ensuring continuous and trustworthy tracking.
  • Data-Driven Optimization: Provides accurate data on ladle cycle times for predictive maintenance and bottleneck identification.
  • Low Cost of Entry & Scalability: The lean, serverless design makes automated tracking accessible without a multi-crore investment.
