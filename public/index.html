LadleTrack-2FA

A Two-Factor Authentication Tracking System for Steel Ladles

Theme: Industry 4.0 / Smart Automation | Category: Software

The Problem & Our Solution

The Problem: Manual ladle tracking is dangerous and unreliable. Single-technology automated systems (like just RFID or just cameras) are vulnerable to single points of failure, which can lead to costly mix-ups.

Our Solution: A network of intelligent "Smart Stations" that uses a two-factor authentication (2FA) process to guarantee the correct identification and location of every ladle, every time.

How It Works (2FA)

  • Factor 1: RFID Identification (Primary ID): Each ladle is fitted with a passive, battery-free, Industrial High-Temperature UHF RFID Tag. This provides a fast, reliable, all-weather primary identification.
  • Factor 2: Visual Verification (Secondary ID): Each "Smart Station" is also equipped with an ESP32-CAM. This low-cost camera captures an image of the ladle's painted number for AI-powered visual confirmation.

The Process: When a ladle passes a station, the system reads both the RFID tag and the painted number. The data is sent to a cloud backend where the two IDs are cross-referenced. A match provides 100% confirmation, while a mismatch triggers an immediate alert. No expensive on-site server is required.

Innovation: Our solution introduces a novel two-factor authentication approach to industrial asset tracking. By cross-validating a robust electronic ID (RFID) with a visual ID (camera OCR), we create a "digital cross-check" system that is far more reliable and error-proof than any single-method solution, all while maintaining an extremely low cost.
